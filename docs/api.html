REST API 参考

Legacy2Modern API v1.0.0 · 基地址 http://localhost:8000 · 完整机器可读规范见 openapi.json。除公开端点外，均需 Authorization: Bearer <token>。

快速开始

# 1. 注册领 100 点
curl -X POST http://localhost:8000/auth/register \
  -H "Content-Type: application/json" -d '{"email":"you@example.com"}'
# → 返回 {"token":"...","credits":100}

# 2. 调用计费工具（每次自动扣点）
curl -X POST http://localhost:8000/mcp/invoke \
  -H "Authorization: Bearer <token>" -H "Content-Type: application/json" \
  -d '{"tool":"legacy-code-audit","params":{"code":"var a=1; if(x==y) TODO"}}'

# 3. 点数不足返回 HTTP 402 Payment Required
1 点 ≈ ¥0.01 参考静态分析引擎，无需 AI 密钥

端点清单（8）

GET/health
健康检查，返回服务状态、AI provider 与工具数量。公开。
POST/auth/register
邮箱注册，返回 user_id / token / credits(100)。重复邮箱返回 400。公开。
POST/refactor需鉴权
AI 代码重构，消耗 10 点；不足返回 402。记录到任务历史。
GET/jobs需鉴权
当前用户的重构任务历史（按时间倒序）。
GET/me需鉴权
当前账户信息（id / email / credits）。
GET/mcp/tools
公开的 MCP 工具目录与定价，供 Agent 自动发现。公开。
POST/mcp/invoke需鉴权
MCP 工具统一计费入口：校验点数 → 分析 → 扣点 → 落记录。工具不存在 404，点数不足 402。
GET/mcp/stats需鉴权
当前账户的 MCP 调用统计与累计消耗。
