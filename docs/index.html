接入方式

stdio 供本地编辑器直连；Streamable HTTP 供云端 Agent 远程调用。谁调用，谁付费。

① stdio（本地 MCP Client）

// 各编辑器 MCP 配置
{
  "mcpServers": {
    "legacy2modern": {
      "command": "node",
      "args": ["path/to/l2m-mcp/index.js"],
      "env": {
        "L2M_API_URL": "http://localhost:8000",
        "L2M_TOKEN": "<your token>"
      }
    }
  }
}

② Streamable HTTP（远程）

// POST /mcp/invoke
{
  "tool": "java8-to-springboot3",
  "arguments": {
    "code": "..."
  }
}
// Header: Authorization: Bearer <token>
// 点数不足 → HTTP 402 Payment Required
